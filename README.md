# Tic Tac Toe

This is the branch for my Tic Tac Toe game!

## About this branch

This is my first full project using Raylib, pretty small but we all start somewhere! \
The game currently contains these features:

* Restarting the game without restarting the program
* Score for both X and O
* Current turn indications
* Amazing win animation (trust)
